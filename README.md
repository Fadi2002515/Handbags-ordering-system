A simple console-based ordering system written in C++.
The program allows users to select handbags from a menu, add multiple items to a cart, and receive a receipt at checkout. It calculates the subtotal, applies a 6% tax, and displays the final total.

This project uses object-oriented programming concepts, including a class with constructors and getter methods, arrays to store menu items and quantities, loops for user interaction, input validation, and formatted output.
